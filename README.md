# Gravity Shift — Version 1

A small gravity-reversal platformer made with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Download or clone this folder.
2. Open `index.html` in a browser.
3. Click **START GAME**.

No build tools or dependencies are required.

## Controls
- **A / D** or **Left / Right arrows** — move
- **Space** — jump while grounded
- **G** — reverse gravity
- **R** — restart

## Core mechanics
- Velocity-based movement and gravity acceleration
- Jumping
- Gravity reversal (down ↔ up)
- Platform collision from either gravity-facing side
- Spikes, failure state, and exit objective

## Files
- `index.html` — game structure and UI
- `style.css` — visual design
- `game.js` — physics, collision, controls, and rendering

## Future ideas
